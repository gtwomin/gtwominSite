# gtwomin

Vue 3 + TypeScript + Vite 專案，已預先設定 Vue Router 與 Pinia。首頁目前保持空白，之後可以再開始加入個人網站內容。

## 開始使用

```sh
npm install
npm run dev
```

## 指令

```sh
npm run dev        # 啟動本機開發伺服器
npm run type-check # 執行 TypeScript 與 Vue 型別檢查
npm run build      # 檢查型別並建立正式版檔案
npm run preview    # 預覽正式版
```

正式版檔案會輸出到 `dist/`。推送到 GitHub 後，可再依最終使用的 GitHub Pages 網址設定部署流程與路徑。
